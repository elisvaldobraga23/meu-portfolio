## ✨ Sobre o projeto

Este portfólio foi desenvolvido com foco em **experiência do usuário, responsividade e performance**, trazendo uma identidade visual moderna com efeitos de glassmorphism e animações suaves.

O objetivo é centralizar minhas informações profissionais, projetos e canais de contato em um único lugar.

---

## 🧩 Funcionalidades

- Menu responsivo com efeito hambúrguer
- Navegação suave entre seções
- Apresentação inicial com destaque profissional
- Seção "Sobre mim" com tecnologias
- Portfólio dinâmico de projetos
- Formulário de contato funcional com EmailJS
- Links diretos para redes sociais
- Layout totalmente responsivo (mobile-first)

---

## 🛠️ Tecnologias utilizadas

- React
- JavaScript (ES6+)
- CSS3 (Flexbox + Grid)
- EmailJS
- React Icons
- Vite
